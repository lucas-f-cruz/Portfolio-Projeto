# Portfólio — Lucas Cruz

## Estrutura

```
src/
├── App.jsx                    ← Arquivo principal
├── data/
│   └── conteudo.js            ← ✏️ Edite aqui: textos, projetos, skills
├── styles/
│   └── tema.js                ← 🎨 Edite aqui: cores e fontes
├── hooks/
│   └── useInView.js           ← Animação de entrada
└── components/
    ├── Fade.jsx               ← Animação suave
    ├── Navbar.jsx             ← Barra de navegação
    ├── HeroSection.jsx        ← Seção inicial com código animado
    ├── SkillsSection.jsx      ← Grid de tecnologias
    ├── ExperienciaSection.jsx ← Timeline de experiências
    ├── FormacaoSection.jsx    ← Timeline de formação
    ├── ProjetosSection.jsx    ← Projetos estilo terminal
    ├── ContatoSection.jsx     ← Formulário de contato
    └── Footer.jsx             ← Rodapé
```

## Rodar o projeto

```bash
npm install
npm run dev
```
